# Codebase Insight v0.1.1

面向产品经理的 DeepSeek Harness 代码理解插件首版。

- 本地只读扫描，JS/TS AST 模块、导入、符号及调用线索提取。
- 产品能力候选映射、证据引用、逻辑架构分层和调用路径。
- 五种可交互视图：全景、能力、架构、流程、依赖；支持搜索、拖拽、缩放、筛选、展开折叠、关系高亮和双向跳转。
- 导出 JSON、Markdown 与无外部依赖的离线 HTML。
- 可选 Harness 模型语义增强，默认关闭；显式授权、预算、取消和引用校验。
- 真实 Cordis/tools 验证；三组固定代码夹具；安全与浏览器交互自动化测试。

## 已知限制

这是有明确边界的首版，不代表完整需求已全部验收。非 JS/TS 语言目前只提供文件/模块结构；静态入口映射为候选能力，不自动确认业务语义、上线状态或生产可用性。流程显示源码调用顺序及条件提示，不是完整控制流。自然语言问答、语义向量搜索、增量分析、影响预测、状态机和图片/PDF 导出为后续功能。真人产品经理体验待完成。参见 docs/acceptance.md。

GitHub Release 发布后，npm 包以相同版本 0.1.1 发布；两者发布状态分别核验。
